자료 요청:

1. 수기 검사표 PDF 견본 2~3장(값·이름은 가린 사본 가능) — 스캔인지, 한 PDF 에 몇 로트인지, 시료 수. 지금 정리한 합불 엑셀 몇 줄
2. 공유폴더 파일 이름 규칙과 「검사해야 할 목록」(생산·출하 계획 등)
3. 스펙 기준표 형태(품번별 항목·하한·상한·단위)
4. 합불 판정 규칙(한 항목이라도 벗어나면 불합격인지, 경계값·빈 칸·재검사)

진행 범위: 1차는 예정 목록 ↔ 공유폴더 대조(업로드 누락) + 검사표를 보며 값을 옮기는 판독 화면 + 스펙 기준표 합불 판정. 손글씨 자동 인식은 견본으로 정확도를 잰 뒤.
