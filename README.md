# data10-13 · 불량 제품 파악

공유폴더의 수기 검사표(「자주 검사 CHECK SHEET」 PDF)에서 모델 · 품번 · 호기와 측정값을 읽고(글자 층은 자동, 스캔은 사람 · AI 반자동), 검사표에 적힌 공차로 호기마다 합불을 판정해 **출하일정과 맞춰 「출하 예정인데 검사표 없음 · 불합격 · 미판정」 리스트**를 만드는 브라우저 도구

|---|---|
| 제출자 | 구민채 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 4차 반영 · 기획서 v2.4 (2026-11-10) — https://data10-13.jobability.co.kr/ |
| 다음 개발 | 실제 스캔 PDF 로 쪽 나누기 · 방향 · 가릴 영역 확인, AI 판독 정확도 재기(합불 엑셀을 정답으로), 사내 허용 AI 연결, 팀 공유 저장 · 공유폴더 정기 점검 |

> **4차(2026-11-10, v2.4)** — ① 스캔 PDF 는 그대로 넣어도 쪽마다 따로 판독하므로 나누지 않아도 됩니다(코드 변경 없음). ② 가릴 영역 **틀 2가지** — 「① 제작 · 가공형 4칸」(결재 위 · 검사자 · 개정 확인란 · 결재 아래, 가공 · 평행도 · ASSY 양식마다 검사자 자리가 달라 셋, 도장은 확인란 · 검사자 2칸) · 「② 상단 결재란 1칸형」(시트 · 각장 · 비용접구간). 공정명으로 자동으로 고르고 설정 · 판독 화면에서 바꿉니다. 세 겹(이 파일 · 쪽만 > 공정 기본 > 모든 검사표)은 그대로이고 공정 기본 안에서 「직접 그린 것 > 틀」. 글자 층이 있는 쪽은 「입안 · 심사 · 결정」 · 「검사자」 · 「개정 … 확인」 낱말 자리로 짐작하는 단추가 있습니다. ③ 출하일정은 **모델 · 호기 · 출하예정 세 칸만** 읽고 나머지 칸은 무시(알림도 없음). ④ 한 칸에 모델별 규격이 둘이면 **모델명 칸의 체크 표시**(✓ · V · ○ · ■)로 모델을 알아내 그 규격으로 판정하고, 모르면 그 칸을 **보류** — 판독 화면에서 「체크한 모델」 이나 항목 규격을 고릅니다.

> **3차(2026-11-10)** — 요청자 답 ①~④ 와 추가 요청 3가지를 반영했습니다. 측정값 칸의 OK 는 합격, 시트 체크시트는 「부착 확인(풍선 체크)」(OK 또는 「체크 수/풍선 수」), 초대형 출하일정 형식(출하예정 · 두 줄 머리 · 연도 없는 「월/일」) · 출하일정 파일 더하기, **한 PDF 의 쪽마다 검사표 한 장** · 같은 호기의 공정별 검사표를 모두 보고 판정, **가릴 영역 세 겹(이 파일 · 쪽만 > 공정 기본 > 모든 검사표)**, 판독 대기 · 보류에 **「수동 판독」** 단추, 쪽마다 **90° · 180° 돌리기**(글자 층이 있는 쪽은 자동, 스캔은 단추). 자세한 경위는 [개발일지](docs/개발일지.md) 2026-11-10.

> 2차는 수강생 답(10-27, 기획서 10장)대로 바꿨습니다 — 양식은 「자주 검사 CHECK SHEET」(한 장에 호기 여럿 · LH/RH 줄), 파일 이름 규칙 없음, 규격은 검사표에 적힘, 한 칸이라도 벗어나면 불합격, 검사 목록은 출하일정. 받은 견본은 칸 배치만 본떴고 **샘플은 지어낸 검사표**입니다(MODEL-A100 · B200, 품번 QA-…). 소속 회사명 · 실제 모델 · 품번은 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://data10-13.jobability.co.kr/** (로그인 · 사용 승인 뒤 열림 — 아래 「로그인 · 승인」)

처음 열면 **가상 샘플이 바로 들어가** ① 출하 대조 화면이 나옵니다 — 출하일정 13대, 검사표 PDF 7개(글자 층 4장은 넣자마자 자동으로 읽음 · 스캔 그림 2장 · 합본 1개 = 1쪽 자주 검사 + 2쪽 시트 부착 체크시트(90° 누운 스캔)), 기준일 2026-10-28.
합본 2쪽에서 「오른쪽으로 90°」 로 바로 세우고, 제작 공정명에 「시트 부착」 을 적으면 풍선 체크 한 줄로 바뀝니다. 「가상 AI 답 예시 넣기」 → 「23/24」 → 불합격. `samples/출하일정_초대형형식_샘플.xlsx` · `출하일정_소형형식_샘플.xlsx` · `출하일정_대형형식_샘플.xlsx` 는 출하일정 파일마다 다른 칸 모양만 본뜬 가상 표로, 자료 넣기에서 「지금 출하일정에 더하기」 로 합쳐 볼 수 있습니다.
② 판독에서 스캔 검사표를 열어 보세요. 「모델 상부 #314504」 는 파일 이름에서 모델 · 호기를 짐작해 노란 칸으로 두고 같은 모델 검사표의 항목으로 칸을 미리 만듭니다. 「AI 로 읽기」 → 「가상 AI 답 예시 넣기(샘플 전용)」 → 「답 읽어 칸 채우기」 로 AI 반자동 흐름도 키 없이 체험할 수 있습니다. 「1013~1015 작업」 은 이름에 아무 단서가 없어 품번 · 호기를 직접 적는 예입니다.

샘플에 일부러 넣은 것 — 비대칭 공차 상한 초과(48 +1.0/-0.5 에 49.3 → 불합격, 문제점 칸 「재가공 후 재측정」), 상한과 같은 값(2746 · 421 → 합격), 빈 칸(→ 보류), 값 없이 체크(V)만 한 칸, 육안 NG(외관), 「1.5 MAX」 항목, 모델 칸에 두 모델(「A / A-E」), 품번이 빈 출하 줄(모델 + 호기로 짝), 숫자로 적힌 호기 칸, 호기 범위(315015~315016), 출하일정에 없는 호기, 표 왼쪽 도면의 LH/RH · 치수 글자(값으로 읽지 않아야 함), 결재 칸 · 검사자 서명(AI 에 보낼 그림에서 가림).

실제로 쓸 때는 설정에서 「모든 자료 지우기」 후 자료 넣기에서 ① 출하일정 엑셀 ② 검사표 PDF(여러 개 · 폴더째)를 넣습니다. 열 이름이 조금 달라도 찾고, 못 찾은 열은 화면에서 골라 연결합니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다(PDF 는 IndexedDB). AI 는 기본으로 아무 데도 보내지 않습니다(프롬프트 복사 · 답 붙여 넣기, 자동 보내기는 설정한 경우에만).

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS, PDF 는 `vendor/pdfjs` 의 pdf.js).

**규격 읽기**: 검사 항목 칸의 「420±1」 「2740 ± 6 mm」 「48 +1.0/-0.5」 「1.5 MAX」 「MAX 0.03」 「MIN 40」 「40 이상」 「8.00~8.10」 → 하한 · 상한. 단위는 따지지 않고 숫자끼리 비교합니다. 육안 항목(측정기 「육안」 · 외관)은 OK/NG.

**판정 규칙(10장 ④)**: 호기마다, 한 칸이라도 하한 · 상한을 벗어나면 불합격(빈 칸이 함께 있어도) · 기준과 같은 값은 합격 · 육안 NG 는 불합격 · 빈 칸 · 못 읽은 칸(「?」) · 규격을 못 읽은 항목 · 모델별 규격 가운데 고를 수 없는 칸은 보류(미판정) · 값 없이 체크(V · ✓)만 한 칸은 합격(설정에서 보류로). 값은 「적힌 그대로」 저장하고 매번 다시 판정하므로, 덮어쓰기 표나 규칙을 고치면 지난 판정도 새 기준으로 바뀝니다.

## 로그인 · 승인

1. 도구 주소에서 「회원가입」 — 이름 · 회사 메일이나 개인 메일 · 비밀번호를 적고 「가입하고 사용 신청」.
2. 관리자가 승인하면 도구가 열립니다(승인 전에는 대문만 보임). 가입 기록은 Supabase 표 `data1013_members`(SQL: `supabase/auth.sql`).
3. 처음 관리자는 과정 운영자이고, 요청자를 관리자로 올리면 요청자가 팀원 신청을 직접 승인합니다.
4. 내 PC(localhost · 파일로 열기)에서는 로그인을 건너뜁니다. 주소 끝에 `?auth=1` 을 붙이면 내 PC 에서도 로그인 대문을 볼 수 있습니다.

업무 자료(출하일정 · 판독값 · PDF)는 지금처럼 이 브라우저에만 저장되고 서버로 보내지 않습니다. 로그인은 「누가 쓸 수 있는가」만 정합니다.
